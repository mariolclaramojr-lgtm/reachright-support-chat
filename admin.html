How to get the Data Backup from Zoho Desk
  1. In Zoho Desk, go to Setup → Data Administration → Data Backup (you need admin access).
  2. Start a backup and download it when Zoho emails you that it's ready.
  3. Unzip it and drop the file with the ticket threads (the email conversations) into the box above.

Don't see Data Backup? Email support@zohodesk.com and ask for a data backup that includes ticket threads.
