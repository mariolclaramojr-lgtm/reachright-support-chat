Install on a website

Any website (WordPress or not): add this before </body>. Replace the two Firebase values with yours from firebase-config.js, and the GitHub address with your GitHub Pages address.

<script src="https://YOUR-GITHUB-NAME.github.io/reachright-support-chat/support-chat.js"
        data-firebase-project="rr-chat-support"
        data-firebase-key="AIzaSyDJaO0kBPTMBeTgyy_-DAe8gIQ_H2SCFv8"
        data-kb="https://YOUR-GITHUB-NAME.github.io/reachright-support-chat/kb.json"
        data-support-email="support@reachrightstudios.com"
        data-ticket-endpoint="firebase"
        defer></script>

WordPress: upload and activate wordpress-plugin/zd-support-chat.zip. There's nothing to set up: the chat appears in the dashboard for administrators, and tickets are emailed by the site to support@reachrightstudios.com.

To edit answers, open admin.html, sign in with Google, make changes and click Publish to Firebase.
